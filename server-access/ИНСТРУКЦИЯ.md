# Вход на F8Q по нику

1. Обновите F8Q Launcher до версии 0.0.8.
2. Откройте настройки → «Аккаунт» → «Вход по нику», введите ник и нажмите «Добавить».
3. Вернитесь на страницу сборки и нажмите «Играть».
4. Для нового персонажа задайте пароль командой `/register ПАРОЛЬ ПАРОЛЬ` (не менее 8 символов, без пробелов).
5. При следующих подключениях вводите `/login ПАРОЛЬ`.

Если вы уже играли на сервере, используйте прежний ник и личный временный пароль от администратора. Команда для смены: `/changepassword СТАРЫЙ НОВЫЙ НОВЫЙ`.

Вход Microsoft можно сохранить. После перехода сервера в режим входа по нику пароль сервера потребуется и таким игрокам.

Официальные скины восстанавливаются автоматически по Minecraft-нику и видны остальным игрокам. Отдельный ресурс-пак для скинов не нужен.

Администратору: файлы уже установлены, изменение серверного режима активируется после перезапуска. Не публикуйте и не пересылайте целиком файл личных временных паролей.
