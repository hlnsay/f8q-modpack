# Вход на F8Q

1. Обновите F8Q Launcher до версии 0.0.9.
2. Откройте настройки → «Аккаунт» → «Вход по нику», введите ник и нажмите «Добавить».
3. Нажмите «Играть». Регистрация и пароль сервера не нужны.

Если вы уже играли, используйте свой прежний ник: сохранены прежние идентификаторы персонажей и их данные. Вход Microsoft тоже можно оставить.

Официальные скины восстанавливаются автоматически и видны другим игрокам. Ресурс-пак для скинов не нужен.

Администратору: EasyLogin и его данные удалены с сервера. Изменение активируется после перезапуска. Без проверки аккаунта и пароля любой подключающийся может указать чужой ник.
