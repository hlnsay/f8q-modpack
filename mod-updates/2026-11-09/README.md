- Polymorph 1.2.0+1.21.1 — клиент и сервер, выбор результата при пересечении рецептов.
- The Leveling 1.2.1 — клиент и сервер, уровни и опыт отдельного снаряжения. Баланс оставлен по умолчанию автора.
- Grassrise 2.0.0 — только клиент; отдельный ресурс-пак не нужен.

Рабочий сервер автоматически не перезапускается. Для включения новых модов нужно обновить клиентов и перезапустить сервер.
