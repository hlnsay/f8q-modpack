# F8Q 1.21.1 [AUTUMN]

Список модов и файлы для сервера F8Q.

## Как установить

1. Установите [Horizon](https://playhorizon.dev) и войдите в аккаунт Microsoft.
2. Скачайте [f8q-updater.exe](https://github.com/hlnsay/f8q-modpack/releases/download/files/f8q-updater.exe) и запустите его.
3. Откройте Horizon, выберите **F8Q 1.21.1 [AUTUMN]** и нажмите «Играть».

Первый запуск устанавливает NeoForge и занимает несколько минут. Дальше моды обновляются сами при каждом запуске.

## Для администратора

После изменения модов в сборке выполните `publish.ps1`. Игра должна быть закрыта.

Публичные моды скачиваются прямо с Modrinth. В релизе `files` лежат только файлы, которых там нет, стартовые настройки и обновлятор.

Токены и пароли в этот репозиторий не добавляются.
