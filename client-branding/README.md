# Экран загрузки F8Q

Используется неизменённый [Custom Loading Screen 0.2.1 для NeoForge 1.21.1](https://www.curseforge.com/minecraft/mc-mods/custom-loading-screen/files/9272043).
Он скачивается с официального CDN CurseForge; конфигурация и логотип находятся в `config/customloadingscreen/`.

Собственный вспомогательный агент меняет только заголовки и значки окон GLFW.
Обновлятор подключает его, если установлен `config/f8q/window-title-agent.jar`.
`window-icon-helper.jar` предоставляет значок раннему загрузчику и игре через общий загрузчик классов.
Файлы не изменяют миры, игровые механики, сетевой протокол или сервер.

Для сборки используются JDK 21+, ASM и ASM Commons 9.10.1. `BuildTitleAgent` переносит
ASM в отдельное пространство имён; BSD-лицензия ASM вложена в готовый агент.
PNG логотипа помещается в `window-icon-helper.jar` как `dev/f8q/window-icon.png`.

Проверено: два запуска полного клиента, завершение загрузки ресурсов и переход в главное меню.
`ProgressTest` проверяет настоящий движок сцены на 0/25/50/75/100% и положение подписи.
